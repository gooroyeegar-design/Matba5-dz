# 5k catalog release checklist

- [ ] catalog integrity reports exactly 5,000 unique recipe IDs
- [ ] all published records have source and license provenance
- [ ] no third-party image is used without redistribution rights
- [ ] API pagination remains server-side
- [ ] APK contains no recipe dump
- [ ] UI contains no emoji food icons
- [ ] recipe detail shows real ingredients and complete cooking steps
- [ ] empty plan state offers an actionable next step instead of a blank screen
- [ ] GitHub Actions APK artifact is green and verified
